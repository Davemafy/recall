# Dependency rules

1. Pin cites do not create new authorities.
2. Same case name does not merge conflicting reporter identities.
3. Critical discussion of an incident authority is excluded from affected-work traversal when the surrounding text explicitly says the authority is invalid, fabricated, unverifiable, or should not be relied upon.
4. Quotation confirmation requires conservative normalized overlap.
5. Proposition similarity is never confirmation.
6. Unknown metadata stays unknown.
7. Every rendered dependency must have evidence.
